# سامانه وب آزمون آنلاین چهارگزینه‌ای

یک وب‌سایت سبک، سریع و کاملاً مستقل برای برگزاری آزمون‌های تستی چهارگزینه‌ای آنلاین روی هاست‌های اشتراکی cPanel (بدون نیاز به SSH، بدون فریم‌ورک‌های سنگین و بدون نیاز به کامپوزر). این سامانه با **PHP خالص** و دیتابیس **MySQL** پیاده‌سازی شده است.

---

## امکانات سامانه

- **پرتال آزمون دانش‌آموزان (`/` یا `/miniapp/`)**:
  - رابط کاربری مدرن، واکنش‌گرا (موبایل و دسکتاپ)، پشتیبانی از RTL، فونت وزیرمتن و تغییر تم روشن/تاریک.
  - ورود آسان دانش‌آموزان تنها با «کد دانش‌آموزی اختصاصی».
  - امکان ثبت‌نام مستقیم با شماره موبایل و کد یکبار مصرف پیامکی (OTP) با قابلیت خاموش/روشن کردن از پنل ادمین.
  - نمایش تایمر زنده آزمون، ناوبری روان بین سوالات و ثبت نهایی نتیجه.
  - کارنامه آزمون و درصد پاسخ‌گویی به صورت لحظه‌ای.
- **پنل مدیریت آزمون‌ها (`/panel/`)**:
  - ورود مستقل با نام کاربری و رمز عبور ادمین.
  - ساخت آزمون با زمان‌بندی دلخواه، کد ورود اختیاری، فعال/غیرفعال کردن و بر زدن تصادفی سوالات و گزینه‌ها.
  - ایجاد و مدیریت بانک سوالات چهارگزینه‌ای.
  - مدیریت دانش‌آموزان و تولید کدهای دانش‌آموزی.
  - مشاهده ریزپاسخ‌های هر دانش‌آموز و خروجی اکسل/CSV نتایج.
  - تنظیمات اختصاصی پنل پیامک و رمز ادمین.
- **تایمر سخت‌گیرانه سمت سرور**:
  - پایان خودکار آزمون‌های زمان‌دار منقضی شده با کران‌جاب cPanel (`cron_finish.php`).

---

## نیازمندی‌ها

- PHP 7.4 تا 8.3
- افزونه `pdo_mysql`
- افزونه `curl` (جهت ارسال پیامک در صورت تمایل)
- افزونه `mbstring` (اختیاری)
- دیتابیس MySQL یا MariaDB

## ساختار فایل‌ها

```text
QuestionBot/
├── index.php          # نقطه ورود اصلی سایت (هدایت خودکار به پرتال آزمون)
├── install.php        # صفحه نصب ۱-کلیکی و ساخت جدول‌های دیتابیس
├── cron_finish.php    # کران‌جاب پایان خودکار آزمون‌های زمان‌دار

├── config.php         # تنظیمات دیتابیس، رمز پنل و کلیدها

├── .htaccess          # امنیت و جلوگیری از دانلود فایل‌های پیکربندی
├── app/               # هسته و کلاس‌های بک‌اند (SmsService, StudentAuth, Db, ...)
├── panel/             # پنل مدیریت وب ادمین
│   ├── index.php      # روتینگ و ورود به پنل
│   ├── pages/         # داشبورد، دانش‌آموزان، آزمون‌ها، سوالات، نتایج و تنظیمات
│   └── views/         # قالب‌ها و استایل پنل
└── miniapp/           # پرتال آزمون دانش‌آموزان (SPA)
    ├── index.php      # صفحه سایت آزمون
    ├── api.php        # API پردازش آزمون و احراز هویت دانش‌آموز
    └── assets/        # استایل‌ها، فونت وزیرمتن و کدهای تعاملی
```

## نحوه نصب روی cPanel

### ۱) آپلود فایل‌ها
محتوای پوشه را در `public_html` (یا یک پوشه دلخواه در هاست) آپلود کنید.

### ۲) ساخت دیتابیس
در cPanel وارد بخش **MySQL Databases** شوید:
1. یک دیتابیس بسازید.
2. یک کاربر MySQL بسازید و با دسترسی کامل به دیتابیس متصل کنید.

### ۳) تنظیم `config.php`
فایل `config.php` را باز کنید و اطلاعات دیتابیس را وارد نمایید:
```php
'db' => array(
    'host' => 'localhost',
    'name' => 'نام_دیتابیس',
    'user' => 'نام_کاربر',
    'pass' => 'رمز_عبور_دیتابیس',
),
'admin_key' => 'یک_کلمه_عبور_تصادفی_برای_نصب',
'panel' => array(
    'user' => 'admin',
    'password' => 'admin1234', // پس از نصب از بخش ابزارها تغییر دهید
),
```

### ۴) اجرای نصب خودکار
آدرس زیر را در مرورگر باز کنید:
```
https://example.com/install.php?key=کلید_admin_key
```
روی دکمه **«ساخت / به‌روزرسانی جدول‌های دیتابیس»** کلیک کنید تا تمام جداول با موفقیت ساخته شوند.

### ۵) تنظیم کران‌جاب پایان خودکار آزمون‌ها
در cPanel &rarr; بخش **Cron Jobs** یک کران‌جاب هر دقیقه تنظیم کنید:
```
wget -q -O /dev/null "https://example.com/cron_finish.php?key=کلید_admin_key"
```

سامانه کاملاً آماده به کار است!
- آدرس ورود دانش‌آموزان: `https://example.com/`
- آدرس پنل مدیریت: `https://example.com/panel/`
